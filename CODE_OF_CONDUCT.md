# Code of Conduct

This project aims to be a respectful and welcoming space.

## Expected behavior

- Be polite and constructive.
- Focus feedback on the code, not the person.
- Be patient with questions and new contributors.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Deliberate disruption of discussions or contributions.
- Sharing unsafe, illegal, or abusive content.

If a problem arises, open an issue privately or contact the maintainer through the usual project channels.
