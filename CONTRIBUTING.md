# Contributing

Thanks for helping improve SlicerSegelin Ender 3.

## Before you start

- Open an issue or describe the change you want to make.
- Keep the existing language style unless you're intentionally improving it.
- Do not commit generated files from `build/`, `dist/`, or `.venv/`.

## Suggested workflow

1. Fork or create a feature branch.
2. Install dependencies with `pip install -r requirements.txt`.
3. Test the app locally before submitting.
4. Keep commits small and focused.

## Folder conventions

- App code: `appSlicerSegelin/`
- Printable models: `models-3d/`
- Sample G-Code: `gcode-examples/`

## Pull requests

- Explain what changed and why.
- Include screenshots or output samples when useful.
- Mention any limitations or follow-up tasks.
