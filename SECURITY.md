# Security Policy

## Supported versions

The latest `main` branch is the actively supported version.

## Reporting a vulnerability

If you find a security issue or a dangerous parsing bug in DXF/G-Code handling:

1. Do not publish the exploit publicly right away.
2. Open a private report or contact the maintainer.
3. Include steps to reproduce, affected files, and the expected impact.

## Scope

This project processes local files only, but malformed geometry can still cause crashes or produce unsafe tool paths. Please test carefully.
